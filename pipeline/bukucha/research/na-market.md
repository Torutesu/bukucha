# Research: 北米(米国+カナダ)AIロールプレイ市場 — 需要・競合・規制

- collected: 2026-08-28
- purpose: 市場を北米に絞る意思決定の根拠と制約条件の棚卸し
- confidence: medium-high(規制 = 法律事務所の解説で高 / 市場数値 = 三次集計で中)

## 1. 需要の実サイズ(米国の月間検索ボリューム)

| キーワード群 | 月間検索数(US) | 示唆 |
|---|---|---|
| "AI chat" | 841,000 | カテゴリの入口。汎用すぎて獲得は困難 |
| "AI girlfriend" | 123,000 | コンパニオン需要の代表語 |
| **個別キャラクター名(ファンダム/クリエイター名)** | **各 20,000〜120,000** | **競合がほぼいない。実質の需要エンジン** |
| "character ai alternative(s)" | 12,000+ | **既存王者からの離脱意向が常時ある** |
| NSFW系クラスタ("nsfw ai", "spicy ai chat" 等) | 合計 200,000+ | フィルタ不満層が可視化されている |
| (参考)日本 "AIチャット" | 74,000 | 日本市場は構造的に別。母国語検索が支配的 |

出典: isekaizero.ai「State of AI Roleplay 2026」(12プラットフォーム・28,253検索語の分析)。**競合の自社ブログなので方向性のみ採用、絶対値は参考値**。

**最重要の構造的知見**: *"Users don't search for an app; they search for someone to talk to."*
→ **人は「アプリ」を検索しない。「話したい相手」を検索する**。
→ 個別キャラ/作品ページが**インデックスされ、共有可能で、ログイン不要で読める**ことが最大の獲得チャネル。
→ **OOC はここが完全に空いている**(SPA・アプリ内完結・作品ページの静的公開なし)。

## 2. 競合マップ(北米)

3つの陣営に分裂している。**どの陣営も満たされていない**のが市場の現状。

### 陣営A: 磨かれているが検閲される(consumer companion)
| サービス | 価格 | 状況 |
|---|---|---|
| **Character.AI** | c.ai+ **$9.99/月** | カテゴリ最大手。**2025年初頭にピーク → 以降 約40%減**。2026年4月に**顔スキャンによる年齢推定**を導入(SB 243対応)。Google Play 5,000万DL |
| **Talkie** | 年額 **$95.99** | 音声起点。Character.AI と同様の減衰カーブ |
| **PolyBuzz** | — | 2025年中盤にスパイク(**ピーク時 月間160万ブランド検索**)後に冷却 |
| **Replika** | サブスク | コンパニオン特化。ロールプレイ用途では非主流 |

### 陣営B: 自由だが摩擦が多い(NSFW-first)
| サービス | 状況 |
|---|---|
| **Janitor AI** | **Limitless Mode は 2025年後半から ID 認証必須**。キャラ設定の自由度が支持される |
| **SpicyChat / CrushOn / Chub** | 無検閲を堀にする。UXの磨きは弱い |

### 陣営C: モデルを差し替える上級者向け
**SillyTavern / NovelAI / AI Dungeon**。技術者寄り。母数は小さいが離脱しない。

### 陣営D(新設): OOC が作ろうとしている場所
**構造化された「遊べる物語」**。stat / endings / keyword book を持つ**ゲーム的AVN**。
陣営A(磨き)と陣営C(構造)の交点。**ここに他社がまだ来ていない** → 我々が狙うべき座標も同じ。

### 決定的な市場力学
> **どのプラットフォームも約18ヶ月を超えてカテゴリ首位を維持できていない。**

Character.AI(-40%)、Talkie(同様)、PolyBuzz(スパイク→冷却)。
**OOC は 2026年4月ローンチ = まだ4ヶ月**。首位交代の窓は 2027年後半まで開いている。
そして**乗り換えコストが極端に低い**(会話履歴はロックインにならない)ことがこの市場の本質。
→ **「乗り換えても自分の物語が失われない」ことを設計すれば、逆に唯一のロックインになる。**

### 市場規模
AIコンパニオン市場は **2027年までに $1.8B** の予測(TechBullion 2026)[要確認: 一次ソース未確認]。

## 3. 規制(これが最大の設計制約)

**2025年後半〜2026年に北米の AI コンパニオン規制が一斉に発効した。後付けでは対応できない。**

### ニューヨーク州 GBL 第47条(AI Companion Safeguards)
- A3008、2025年5月9日署名、**2025年11月5日発効**。全米初
- 適用対象の定義(3要件の関係シミュレーションテスト):
  1. **セッションをまたいで情報を保持**しパーソナライズする
  2. 直接の応答を超えて**感情に関する質問を自発的に行う**
  3. ユーザー個人の事柄について**継続的な対話を維持する**
  → **我々のプロダクトは1と3に確実に該当する。適用対象と見なすべき**
- 義務:
  - **AI であることの明示**
  - **3時間ごとに「相手はAIである」旨のリマインダーで対話を中断**
  - **自傷・自殺念慮の検出と危機介入プロトコル**(危機センター/ヘルプラインへの誘導)
- 罰則: 州司法長官が執行、**1日あたり最大 $15,000**。自殺予防基金に充当

### カリフォルニア州 SB 243(Companion Chatbots)
- 2025年10月13日署名、**2026年1月1日発効**
- 義務: AI であることの開示 / **未成年への休憩リマインダー** / 自傷コンテンツへの危機対応プロトコル
- **2027年7月1日から** California Office of Suicide Prevention への年次報告
- 執行: **私人訴権あり**。実損害または**1違反あたり $1,000** のいずれか大きい額 + 弁護士費用
- 併走: **AB 1043**(アプリストアでの年齢確認)

### プラットフォーム(Apple / Google)
- Apple は2025年に年齢レーティングを刷新: **13+ / 16+ / 18+ を新設、12+ と 17+ を廃止**(4+ / 9+ は維持)
- 全アプリで新レーティング質問への回答が **2026年1月31日** までに必須化
- **2026年7月9日にソーシャル機能の申告項目を追加。フィードを持つアプリは 13+ が下限**。**2026年9月から回答必須・未対応は審査保留**
  → **本プロダクトはホームフィードを持つ = 13+ 下限が確定。今まさに対応期限**
- Apple は AI アシスタント/チャットボット機能もレーティング判定の対象に含めることを明示
- 業界実態: AIコンパニオンアプリ4,346本のうち**60%以上が未成年向けレーティング**(deepsee.io)。**規制の次の標的**

### 我々の結論
| 制約 | 設計への落とし込み |
|---|---|
| NY: 3時間ごとのAIリマインダー | リーダー画面に**セッション時間トラッカー + 非破壊的なインタースティシャル**を実装。物語の没入を壊さない演出("intermission")で包む |
| NY/CA: 危機介入 | 入力・出力の両方に自傷検出。検出時は**LLM生成を止めて**固定の危機リソース(988 Suicide & Crisis Lifeline / Talk Suicide Canada)を提示 |
| CA: 未成年への休憩リマインダー | 年齢に応じたセッション上限とリマインダー間隔 |
| CA: 私人訴権 $1,000/違反 | **開示とログを実装レベルで証跡化**。「やったつもり」は通用しない |
| Apple: フィード = 13+ 下限 | ストア版は **13+ の全年齢体験に固定**。成人向けはストアに載せない |
| AB 1043 / 年齢確認の潮流 | 成人層は **Web のみ + 第三者年齢認証**。自己申告は「合理的な検出措置」として不十分と既に判断されている(Character.AI の顔スキャン導入がその証左) |

> **OOC の弱点**: App Store 13+ のまま Adult Content 層を持つ(research/ooc.md §8)。
> 規制強化局面で**構造的リスクを抱えたまま走っている**。ここを正しくやることは、道義的に正しいだけでなく**競争優位**になる。
> ストアから消えるリスクを負わないプラットフォームは、クリエイターにとって「作品を置ける場所」として選ばれる。

## 4. 北米ローカライズで日本版から変えるべきこと

| 項目 | 日本版(旧方針) | 北米版 |
|---|---|---|
| 言語 | 日本語のみ | **英語のみ**(OOC も英語のみ。中途半端な多言語より深さ) |
| 文体 | 一人称ラノベ、地の文 = 明朝体 | **二人称現在形の web novel / interactive fiction 文体**。セリフは `"…"`、行動は `*…*`(SillyTavern 以来のデファクト) |
| ジャンル語彙 | 夢小説 / 乙女 / TL / BL | **isekai, fantasy romance, enemies-to-lovers, slow burn, found family, dark romance, LitRPG, academy, cyberpunk** |
| タグ文化 | 欲望タグ(#溺愛 #執着) | **AO3 型タグ**(ship tag / trope tag / warning tag)。北米ファンダムの母語 |
| 決済 | ストア課金 + Web | **Stripe(Web)を主、ストアを従**。OOC も Stripe 直結を採用済み |
| フォント | 明朝体 = 高級感 | **セリフ体(Literata / Source Serif)= 読書体験**。明朝体の記号は通じない |
| 年齢制度 | R15 寸止め + 安心フィルタ | **13+ (ストア) / 18+ (Web・年齢認証)** の2層。§3の規制に従う |
| 法令表記 | 特商法・資金決済法 | **ToS / Privacy / DMCA / CCPA-CPRA(カリフォルニア) / PIPEDA(カナダ)**。特商法は不要 |
| 通貨 | 円・前払式支払手段規制 | **USD / CAD**。米国はギフトカード規制が州法ベースで日本より緩いが、**未使用残高の失効ポリシーは州法(escheat)確認が必要** [要確認] |
| 日付・単位 | YYYY/MM/DD | **MM/DD/YYYY**(OOC のバンドル内も `MM/dd/yyyy`) |

## 5. 北米で効く獲得チャネル(OOC が使っていないもの)

1. **作品ページの静的公開 + SEO**: §1 の通り需要エンジンは固有名詞検索。作品/キャラのページを**ログイン不要・SSR・OGP付き**で公開する。OOC は SPA でこれを捨てている
2. **Reddit**(r/CharacterAI, r/SillyTavernAI, r/AIDungeon 等): 北米ロールプレイ層の実際の集積地。移民誘導の主戦場
3. **Discord**: クリエイターコミュニティの標準。OOC は公式Discordの存在が確認できていない [要確認]
4. **AO3 / Wattpad からの作家移住**: 「書いたものが遊ばれ、収益になる」提案。**OOC の著作権譲渡条件では絶対に来ない層**(research/ooc.md §7)
5. **"Character.AI alternative" クラスタ**(12,000+/月): 離脱意向は常に存在する。比較ページを持つ
