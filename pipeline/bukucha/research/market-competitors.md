# AIキャラチャット市場 調査レポート（生データ）

調査日: 2026-08-06。以下、**[事実]** = 出典に基づく情報、**[推定]** = 二次情報・レビュー記事や筆者推論による情報。未確認事項は明示。

## 1. 主要競合の機能・UX比較

### 1.1 Character.AI（米国、グローバル最大手）

- **[事実]** ユーザー作成キャラ2,000万体以上、MAU約2,000万。2025年売上約$50M（前年比+66%）、2026年は$60M超ペースと推計（Business of Apps / Sacra / completeaitraining）
- **[事実]** 主要機能:
  - **Personas**: ユーザー側の自己設定をキャラが読み込んで会話に反映
  - **グループチャット**: 最大10体のAIキャラ、モバイル限定（旧デスクトップ「Rooms」は2024年9月廃止）
  - **Character Calls**: リアルタイム双方向音声通話（グループ音声は非対応）
  - **Imagine**（2026年初）: 会話の場面を画像・短尺アニメ化
  - **Stories**モード: ガイド付きアドベンチャー（選択肢付きストーリー）
  - ワードゲーム（Speakeasy / War of Words、2025年1月〜、主に有料層向け）
- **[事実]** 課金: c.ai+ が$9.99/月、年額$94.99（約$7.92/月）。内容は高速応答・優先アクセス・先行機能・音声・広告非表示。**モデル自体は無料版と同一**（速度と利便性への課金）
- **[事実/推定混在]** 2026年に「Charms」という仮想通貨経済を導入との報道: デイリークエストで獲得、クリエイターへの「投げ銭」、プレミアム音声解錠、スローモード回避に使用（aiinsightsnews — 二次ソースのため精度は要検証)
- **[推定]** 収益構成はサブスク+広告（キャラ切替時）+マイクロトランザクション+Googleへのライセンス契約のハイブリッド

### 1.2 韓国勢

**Zeta（Scatter Lab社）**
- **[事実]** 韓国でZ世代の利用時間がChatGPTを上回る（2025年10月: Zeta 7,362万時間 vs ChatGPT 4,828万時間）（Korea Herald）
- **[事実]** 自然言語でのキャラ作成、AI画像でキャラビジュアル生成、ワンタップで文脈画像を生成する「スナップショット」機能、音声機能。「小説のようなインタラクティブ・ストーリーテリング」を標榜
- **[事実]** 基本無料+広告で参入障壁を低く設計。2026年Q2に黒字化: 四半期売上52億ウォン、営業利益9億ウォン（営業利益率17%）。500億ウォンの資金調達（Seoul Economic Daily）
- **[推定]** 日本語版「Zeta」も日本で展開中。日本のユーザーコミュニティでは「（日本語）性能は低い」との評価あり（note比較記事）

**Crack / キャラぷ（Wrtn Technologies社）**
- **[事実]** 韓国で2025年3月にCrackをローンチ、3ヶ月後に日本で「キャラぷ」として展開（2025年6月10日）。韓国ではチャットアプリの売上ランキング首位に。Wrtn全体でARR $100M超えペース（Fortune 2026年3月）
- **[事実]** キャラぷ: AIキャラ8,000体以上（ローンチ時）、文章入力でキャラ作成、Web/iOS/Android対応、キャラの公開/非公開設定
- **[事実]** 課金: コイン制。新規登録約300コイン、ログインボーナス24コイン/日、1〜7コイン/メッセージ（1コイン≒1円）（note比較記事による実測系情報）
- **[事実]** **クリエイター報酬制度あり**: キャラの利用実績・いいね・コメントに応じてクレジット還元、条件達成で「公式クリエイター」認定、人気キャラで継続収入（forest.watch.impress / plus-web3）→ 日本で稼働中の数少ないクリエイターエコノミー実装例
- **[推定]** NSFWは厳しめとのユーザー評価。公式Discordコミュニティが活発

### 1.3 中国勢

**Talkie / 星野（MiniMax社）**
- **[事実]** 星野（中国版）+Talkie（海外版）で累計ユーザー1.47億人（2025年9月時点）、中国AIコンパニオン市場で圧倒的首位。Talkieは2024年上半期だけで約1,700万DL（Sensor Tower推計）。MiniMax売上は年$70M超と推計（36Kr / note記事）
- **[事実]** UX: 電話をかけるようなコールUI、キャラごとの音声（TTS）、**カード型ガチャシステム**（キャラカード・パーソナリティ変種・レアリティ、期間限定イベントジェムで限定カードを引く）
- **[事実]** 課金: Talkie+ 約$9.99/月（地域によりBasic $3.99 / Pro $7.99〜$24.99 / Premium $15.99の階層あり）、サブスクにデイリージェム付与。別途ジェムバンドル$1.99〜でトークン購入（サブスク+従量+ガチャの三層構造）
- **[事実]** 無料枠は1日50メッセージ程度との報告（roborhythms）

**猫箱（ByteDance）**
- **[事実]** 星野の競合として急成長も、DAUは5万人強で星野に大きく劣後（2024〜25年時点の報道）

**Linky AI**
- **[事実]** ガチャ機構あり（3種の「マジックカード」、カード情報の編集は1回のみ可）。サブスク$9.99/月・年額$89.99+コイン課金でカードを引く（10連約$15）。モデレーションは比較的厳格でNSFW自由度は低い（tipsy.chat等の二次記事）

**規制動向 [事実]**: 中国は2026年に世界初の「AI恋人」規制を導入、未成年には全面禁止（AI新聞/ExaWizards）— 日本にも将来的な規制議論が波及する可能性は**[推定]**

### 1.5 チャットノベル系（UX参考）

- **[事実]** **TELLER**: 国内DL数約360万でトップクラス。LINE風チャットUI、セリフのプッシュ通知や着信の擬似演出。投稿機能は弱い（アイコン選択不可・並び替え不可との批判）
- **[事実]** **peep**: DL数約80万。チャットノベル・イラストノベル・シネマノベル等の複数形式。「スキマ時間にサクッと読める」設計。オリジナル小説・マンガ・Webtoonへ拡大
- **[事実]** **Balloon**: 海外チャット小説アプリの模倣で新規参入、投稿機能は限定的
- **[推定]** チャットノベルUXの核: タップ/スクロールでメッセージが逐次表示されるテンポ感、既読的な演出、通知演出による没入。この「読み物としての連続テキスト体験」とAIチャットの融合はまだ国内で決定的なプレイヤーが不在（Zetaが「小説的ストーリーテリング」を最も明確に標榜）

## 3. リテンション設計

- **[事実]** **プロアクティブメッセージ（キャラから先に連絡）**: 記憶システムと接続し「ユーザーが実際に言ったこと」を参照するプッシュ通知は、汎用通知の数倍のコンバージョン。タイムスタンプではなく会話文脈ベースの再エンゲージトリガーが有効。「再エンゲージ施策」ではなく「キャラが自分の生活を持ち連絡してきた」というキャラクター設計として実装するのが定石（SoulLink / agnost.ai）
- **[事実]** **親密度システム**: Nomiは7段階の親密度レベルを実装、対話量で関係性が変化。Talkieはカードレアリティ、キャラぷはランキング/いいねでゲーミフィケーション
- **[事実]** **記憶システム**: 「数週間前の発言を自然に持ち出す」体験がリテンションの核。多層メモリ（即時/短期/長期/コアアイデンティティ/関係履歴）で感情的に重要なイベントを優先し瑣末な詳細を減衰させるカスケード構成が推奨（aicompanionpick / digitalhumancorp）
- **[事実]** **先行指標**: 会話の長さ・個人性・多様性の推移（conversation health）が離脱の数週間前に予兆を示す（agnost.ai）
- **[事実]** デイリーログイン報酬: キャラぷ（24コイン/日）、Talkie（デイリージェム、デイリーチェックイン）、Character.AI（デイリークエスト→Charms）
- **[事実]** TELLERの「セリフのプッシュ通知・擬似着信」はチャットノベル文脈での通知演出の先行例
- **[推定]** 研究面の注意: AIコンパニオンの「感情的操作」を扱うarXiv論文（2508.19258）が存在し、離脱抑止型の情緒的引き留め（guilt-tripping等)は倫理・規制リスクとして認識されつつある

## 4. クリエイターエコノミー

- **[事実]** Character.AIには**直接的な収益分配プログラムは現在存在しない**。2026年の「Charms」でユーザー→クリエイターへの投げ銭が可能になったとの報道あり（要一次確認）
- **[事実]** キャラぷ（Wrtn）: 利用実績連動のクレジット還元+公式クリエイター認定制度が稼働（国内先行例）
- **[事実]** FANZAキャラチャット: IP権利者との「提携パートナー」募集モデル（レベニューシェア条件は非公開）
- **[事実]** 国内クリエイター課金プラットフォームの手数料相場:
  - pixiv FANBOX: 10% → **R-18設定は2025年9月から12.9%に引き上げ**
  - Fantia: イラスト・漫画10%（実写のみ13%）
  - Skeb: 9.8%（5,000円以上のリクエストで条件により6.8%）、著作権はクリエイターに残る
- **[推定]** 相場観: 国内UGC課金の手数料は10〜13%が受容ライン。App Store/Google Play経由だと更に15〜30%のストア手数料が乗るため、Web課金併用（キャラぷもWeb版あり）が実質必須。クリエイター報酬は「利用量連動ポイント還元」（キャラぷ型）と「直接支援/投げ銭」（FANBOX型）の2系統があり、Pixiv的コミュニティを狙うなら両方の併設が論点

## 5. LLM技術要件

- **[事実]** ロールプレイ向けオープンモデルの定番（2026年時点のコミュニティ評価）:
  - TheDrummer系ファインチューン: Rocinante（~12B、軽量）、Cydonia（~22-24B、長セッションで安定した文体）
  - Nous Hermes 3（創作・RPで「共作者的」な文体）
  - Dolphin-Mistral 24B（推論性能高、24GB+ GPU）、Gemma Abliterated 9B（12GBで動く全能型）
  - 旧世代の定番: MythoMax L2 13B、Psyfighter 13B、uncensored Llama 3系
  - **[推定]** 日本語RP品質はこれら英語系FTでは不十分な可能性が高く、日本語特化FT（あるいはフロンティアモデルAPI+プロンプト制御）との比較検証が必須。ZetaやキャラぷはFT自社モデル/商用APIのハイブリッドとみられる（非公開）
- **[事実]** **長期記憶アーキテクチャ**: MemGPT/Letta が業界標準パターン — OS的階層メモリ（コアメモリ=常時コンテキスト内・エージェント自身が編集可 / 会話メモリ / アーカイバルメモリ=ベクタDB検索）。関連研究では「抽出済みサマリーより逐語チャンク検索が長期会話で優位」との報告あり（arXiv 2601.00821）
- **[事実]** フロントエンド参考実装: SillyTavern（キャラクターカード、World Info/ロアブック、グループチャット、ペルソナ、RAG、詳細なプロンプト制御）— キャラ定義フォーマット（character card）のデファクト
- **[推定]** ストリーミング: SSE/WebSocketによるトークンストリーミングは全競合が実装済みで前提条件。チャットノベル的UXでは「文単位の逐次表示+タップ送り」への変換レイヤが独自設計ポイント
- **[事実]** **モデレーション**:
  - OpenAI Moderation API: 無料、テキスト+画像13カテゴリ、カスタマイズ不可
  - Azure AI Content Safety: 有料、重大度グレード付き、Prompt Shields（ジェイルブレイク検知）、カスタムカテゴリ対応
  - **[推定]** NSFW許容アプリの場合、「未成年関連・実在人物・違法内容は遮断、成人向け表現は年齢確認後に許可」という多段フィルタ（入力/出力両方)+自前分類器の構成が一般的。ストア版とWeb版でフィルタ水準を分ける運用（FANZA=Web、キャラぷ=ストア版マイルド）が国内の実態

## 6. 日本市場特有の論点

- **[事実]** **資金決済法（前払式支払手段）**: アプリ内通貨（ジェム/コイン）は自家型前払式支払手段に該当。基準日（3/31・9/30）の未使用残高が**1,000万円超**で届出義務+**残高の1/2以上の発行保証金供託**義務。回避策は (a) 残高を1,000万円以下に維持、(b) **有効期限を6ヶ月以内に設定**（この場合適用除外）。ガチャ用通貨も対象（ベリーベスト/LEON/トップコート法律事務所の解説）
  - **[推定]** 多くの国内アプリがボーナスコイン（無償付与分）と購入コインを分別管理するのはこのため。無償付与分は前払式支払手段に該当しない
- **[事実]** **特定商取引法**: 通信販売に該当するため「特商法に基づく表記」（事業者名・返品条件等）が必須。**[推定]** サブスクは2022年改正の最終確認画面表示義務（解約導線明示）に留意
- **[事実]** **年齢確認・青少年保護（2026年の動向）**:
  - こども家庭庁が2026年6月に検討WG中間整理骨子案を公表。SNS事業者への年齢確認義務付けを検討、**2027年通常国会で青少年インターネット環境整備法改正案の提出を目指す**（日経/ReseEd）
  - ChatGPTは2026年1月から利用パターン等の複数シグナルによる年齢推定を段階導入 — AIチャットにも年齢確認圧力が波及中
  - 中国は未成年への「AI恋人」全面禁止を導入済み（規制の国際的先行例）
- **[事実]** **ストアポリシー**:
  - Apple 1.1.4: 「性的興奮を目的とした露骨な描写」は禁止。**2026年6月8日改定でAIチャットボット機能が「センシティブなコンテンツの頻度」に与える影響を年齢レーティングに反映するよう義務化**
  - Google Play: 「主として性的満足を目的とする生成AIアプリ」を明示的に禁止、AI生成コンテンツポリシーでレポート機能等を要求。2024年にAIヌード化アプリを一斉削除
  - 2026年7月、米当局の要請でAppleが「nudify」系8アプリを削除 — 執行は強化傾向
  - **[推定]** 帰結: NSFWをやるならWeb直販（FANZA型）一択。ストア版は全年齢+Webへの誘導もリンク規約に注意（External Link規約）。「ストア版=健全、Web版=成人向け」の二面運用が国内の事実上の標準
- **[推定]** その他: R18を扱う場合は決済側の制約（Visa/Mastercardのアダルト決済規制強化）が実務上最大の隘路になる可能性。FANZA/DMMポイント経済圏との提携が国内では現実的な回避策
