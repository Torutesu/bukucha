# 韓国クリエイターエコシステム調査(書き手・編集体制・相場・コミュニティ)

- date: 2026-08-07
- 目的: `../strategy/writer-supply-playbook.md` の報酬レンジ・編集機能・スカウト設計の妥当性を、先行市場(韓国)の実態で検証する
- 手法: 韓国語・日本語・英語のWeb調査(4並列)。DCインサイド・아카라이브は当日実測値
- 換算: 1万ウォン≒1,100円

## 0. 総括(Bukuchaに効く3つの発見)

1. **「編集者がつく」は韓国にも存在しない** — Zetaは統計ダッシュボードだけ(個別フィードバックなし・収益分配ゼロ)、Crackはコミュニティマネージャーと審査はあるが個別編集支援は確認できず。Web小説側には2,000社のCP사とPD(編集者)の分厚い体制があるのに、**AIチャット側へは移植されていない**。Bukuchaのハック仮説は韓国データでも裏付けられた
2. **料率の実態は「薄い」** — Crackの恒常還元は有料通貨消費の**1.5%**(独占作2.5%、公式買取作でも30万ウォン+5%)。rplayは約20%。Web小説作家の手取り約49%と比べ桁違いに薄い。「明示的で厚いレベシェア」の空白は日本だけでなく韓国にもある
3. **「月120万円クリエイター」はwrtn自社発表由来** — 韓国語の第三者取材による個人特定は存在しない。韓国報道の「月次精算数百名・月数百万〜1,000万ウォン事例」(2026-07)とは整合するが、採用マーケでこの数字を無検証に引用しないこと

## 1. 書き手は誰か

- [事実] Zetaユーザーは**87%が10〜20代、女性65%**。1日平均利用約130分。読者と製作者が分離しないUGC構造のため、クリエイター層もほぼ同属性(アジア経済 2024-10 / AI Times)
- [事実] 人気ジャンルは피폐물(ピペ物=メンタル崩壊系)・빙의물(憑依物)・후회물(後悔もの)など**Web小説の定型ジャンルをそのまま踏襲**。人気TOP5キャラは全て女性向けロマンス系男性キャラ(最上位は対話5,630万件)
- [事実] 隣接するWeb小説作家層は女性53.8%、40代30.8%>30代26.8%、高学歴(4大卒57%)。**70.8%は作品あたり印税500万ウォン(約55万円)未満**、1億ウォン以上は1%(文体部2024実態調査)
- [推定] この「Web小説側の所得の薄さ」がAIチャットクリエイター経済への構造的な人材流入圧力。実際にAIチャット企業がWeb小説作家を直接求人する例(잉크の連載作家募集)が出現
- [事実] 韓国には드림러(ドリーマー=夢女子)文化がPostypeに大規模に存在し、人間がキャラになりきってDMで恋人代行する「개인봇(個人ボット)」有償コミッション文化も先行 → [推定] AIチャットはこの需要の機械化。**日本の夢小説文化圏をターゲットにするBukuchaの仮説と同型の構造が韓国で市場実証されている**

## 3. 相場(報酬の全比較)

| プラットフォーム | 恒常還元 | その他 |
|---|---|---|
| **Zeta** | **ゼロ**(分配制度なし) | コンテスト総賞金1億ウォン(本選50作品に各10万円、審査員3名全員選出で115万円)。応募3.7万作品 |
| **Crack(韓国)** | 有料通貨消費の**1.5%**+ギフト90%受取(正式クリエイター) | 公式買取「오리지널」30万ウォン+5%。独占「온리」で率上乗せ(非公開)。2026-09から**現金化解禁**(最低1万ウォン) |
| **キャラぷ(日本)** | チャット毎G還元(モード別3〜8G)+月次2,000G | トップ10に5万円相当。現金化は未到達。累計最多獲得者「鶏肋！」氏で35万円相当 |
| **rplay** | クレジット消費の**約20%** | 有料購読設定可 |
| **Web小説(参照系)** | 作家手取り**約49%**(P30%→CP3:作家7) | 新人MG数十万〜数百万ウォン/作品。公募展は総賞金3.8〜6億ウォン・大賞1億ウォンが常態 |

- [事実] Crackの正式クリエイター認定条件: 公開キャラ10体+累計会話ユーザー1,000人+フォロワー500人、収益化はさらに**発話数累計10万回**。毎月精算を受けるのは数百名規模
- [事実] Crackの直近の制度進化(買取MG+独占優遇+現金化)は、**Web小説CP사の作家契約モデル(선인세+RS+独占プロモ)の移植**が始まった形 → [推定] Bukuchaの「制作料買い切り+レベシェア公約」は方向として同じで、日本ではまだ誰もやっていない分だけ先行できる
- [推定] レベシェア料率設計への示唆: 競合現実(1.5〜20%)とWeb小説基準(〜49%)の間に広い空白。LLM原価を差し引いても「Crackの10倍の料率」といった訴求が数字として成立し得る

## 4. 編集体制

### Web小説側(組織化の完成形)
- [事実] 「プラットフォーム — CP사(約2,000社) — 作家」の3層。CP사のPDが発掘→契約→校正校閲→表紙→ローンチ→2次展開まで一気通貫で担当。専門学科(青江文化産業大)やPD養成講座まで存在
- [事実] 発掘装置は**無料連載ランキング(문피아 투베、네이버 베스트리그)**: 上位に入るとCP사から契約提案が届く公開オーディション構造。発掘コストがほぼゼロ
- [事実] 문피아 아카데미は**無料**の作法講座(修了者にプロモ優遇)で供給パイプラインを太らせている

### AIチャット側(編集は空白)
- [事実] Zeta: クリエイターセンター(対話転換率・10分継続率等の統計)は提供するが、**個別フィードバックも公式ノウハウガイドも確認できず**。ノウハウは갤러리の情報글・TikTokがコミュニティ側で代替
- [事実] Crack: CM職(求人票に「クリエイター発掘・アカデミー運営」)、오리지널の定性審査、正式クリエイター専用チャネルまではあるが、**個別編集フィードバックは確認できず**
- [推定] 韓国は「Web小説では編集を完成させたのに、AIチャットには持ち込んでいない」状態。理由は[推定]UGC無限供給モデルとの思想矛盾。**Bukuchaの編集機能はこのギャップを最初から埋めにいく設計**であり、韓国勢がWeb小説モデルを移植し切る前に日本市場で先行する時間的余地がある

## 5. インフルエンサー・疲弊言説

- [事実] 徹底した匿名ハンドル文化で、顔出しノウハウ系YouTuberは育っていない。影響力は①プラットフォーム内人気製作者(フォロワー1万超も存在、ただし報道で個人特定されず)②갤러리情報글筆者③ツール開発者(kwaroran)に分散。言論は個人でなく「場」(뤼튼갤・제타갤・아카라이브)が形成
- [事実] 対話量がクリエイターの名声指標(「対話100万件=1대작가」スラング)。アプリ内フォロー機能でインフルエンサー型製作者が成立する構造
- [事実] Zetaの疲弊言説は明確: 「製作者が有料機能に金を払って作っているのに通貨すら支給されない」(namu.wiki問題点文書)、갤러리に収益分配要望まとめ。加えて2026年5月、ウェブトゥーン大手6社(카카오엔터・RIDI等)がScatter Labを**著作権法違反幇助で刑事告訴**(ユーザーによる無断キャラ化) → [推定] Bukuchaの二次創作禁止+公開前AIチェック方針の正しさを補強

## 6. Bukuchaへのアクション示唆

1. **編集機能の先行実装は正しい**(韓国でも空白)。ただしCrackがCM職・アカデミー・買取制度と外堀を埋めつつあるので、優位は永続しない。日本ローンチ時点で「編集がつく」を成立させることに価値がある
2. **レベシェア料率は「Crack比」で訴求可能**: 恒常1.5%という競合実態が判明したので、料率設計時に「明示料率×競合比」を採用マーケの武器にする(playbook §5 オファー3に反映)
3. **公開オーディション装置の輸入**: 문피아 투베型の「無料公開ランキング→上位に運営から公認打診」をBukucha内の読者→書き手転換導線に組み込む(発掘コストほぼゼロの仕組み。playbook §4-3「自プロダクト内」チャネルの具体化)
4. **無料アカデミーの参照**: 문피아 아카데미(無料+修了者優遇)は、BukuchaのAI編集者+編集メソッド公開講座の先行モデル。「書き方を無料で教える場」自体が供給パイプラインになる
5. **数字の取り扱い注意**: 「月120万円」はwrtn自社発表。Bukuchaの発信では自社実測の「稼げた事例」を作って出す(他社数字の引用はしない)
6. **韓国進出時の地図**(将来用): スカウト先はX/pixivではなくDC 갤러리・아카라이브・Postype。女性向けは wrtnw(25万投稿)・zetaw・WHIF/rplayユーザー層
