## 2. 機能一覧

**事実(公式サイトHTML・App Store・記事から確認):**
- **チャット**: 1:1およびグループ(複数キャラ登場の物語形式)。モード制(後述)。キャラの表情差分・シーン画像・ステータス表示演出
- **チャットモード**(消費ゴールドが異なる複数エンジン): パワーチャット(2〜3G)/ブーストチャット(5G)/スーパーチャット(8G、長期記憶・文脈理解)/ウルトラチャット(8G)/ハイパーチャット(24G)。2025年7月にハイパー/ウルトラ追加。App Store記載では「スーパーチャット、プライムチャット、ウルトラハイパーモード」の表記もあり(名称は改廃が激しい)
- **記憶機能**: 「要約メモリ」(長い会話を自動要約してキャラの記憶を補助、2025年7月実装)+「ユーザーノート」(ユーザーが恒久設定を手書き登録。要約メモリからのコピー推奨。機能拡張はゴールド消費)
- **画像**: (a) キャラ作成時のシーン画像事前登録+キーワードトリガーで即時表示(リアルタイム生成でなく事前登録画像呼び出し=低レイテンシが差別化)、(b) 「画像作成」(image-builder)メニュー=リアルタイム画像生成(ゴールド消費)、(c) キャラ画像のAI生成/アップロード
- **ビジュアルノベル**(2025年12月18日正式リリース): 選択肢分岐・マルチルート・キャラごとの好感度/ステータス数値変化・フルスクリーン演出。専用制作ツール(背景/日付/場所、登場人物、分岐フローチャート、ステータス変化、冒頭選択肢を設定)。後に「ファストモード」「背景削除機能」追加
- **キャラ作成**(マイキャラ): 5ステップウィザード
- **探索/発見**: ホームのセクション型フィード、ジャンル別セクション(18種)、ランキング(今日/全体)、タグ検索(/character-tags)、キーワード検索、「注目キャラ」「新星作成者のキャラ特集」「{nickname}様におすすめのキャラ」(パーソナライズ推薦)、「フォロー作成者の新作一覧」、公式キャラ「キャラぷオリジナル」(/original)
- **チャット履歴**: サイドバー常設。タブ「全て/ストーリー/ビジュアルノベル」。ストーリーは記憶され、いつでも再開・途中で設定修正可能
- **ソーシャル**: いいね(/liked に保存)、コメント(キャラ詳細にコメント欄、並び替え「いいねが多い順」)、フォロー(/following)、応援(応援ゴールドの投げ銭)、Discordコミュニティ
- **通知**: 通知オンで+30G付与の報酬設計あり(=プッシュ通知あり)
- **音声**: 音声読み上げ強化が「将来開発予定」と取材記事に記載 → [推定] 現状の音声機能は無いか限定的
- **AI基盤**: OpenAI / Claude / Gemini等とパートナーシップ、用途別に最適モデルを切替(取材記事)。過去記事ではGPT-4o、Claude 3、Stable Diffusion 3の採用言及

## 4. チャットUIの詳細

- **表示形式**: 通常チャットはメッセージ逐次表示型だが、内容は**小説(ノベル)風**。地の文(三人称の情景・心理描写)とカギ括弧「」のセリフが混在した長文をキャラ側が返す。実例(公式detailページのプレビューより): 地の文数段落+`「ああ。きみ…先週から配属された{user}さん、だよね」`。`{user}`/`{{user}}`プレースホルダでユーザー名が差し込まれる
- ビジュアルノベルモードはフルスクリーン演出(背景+立ち絵+テキスト+選択肢+好感度数値)。キャラの表情差分・シーン画像・ステータス表示演出あり(App Store説明)
- **返信候補**: あり。クリエイターが「おすすめ回答」を最大3つ設定でき、チャットで候補提示される。ビジュアルノベルでは明示的な選択肢分岐
- **画像表示**: 会話中にキーワードトリガーで事前登録シーン画像がインライン表示
- **メニュー**: チャット画面右上メニュー → ユーザーノート/要約メモリ。途中でキャラ設定内容の修正が可能
- **モード切替**: チャットごとにパワー/スーパー等のモード選択(消費G表示)
- **再生成・編集**: [推定] 再生成機能はある可能性が高いが、一次情報での明示確認はできず
- **ストリーミング**: [推定] 逐次ストリーミング表示。レビューに「返答生成が速い」との言及があるが表示方式の明示記述は無し
- スマホアプリはフルスクリーン・ナビ最小化で没入重視、PC版はサイドバー付き標準レイアウト

## 5. キャラ作成フロー

5段階ウィザード:
1. **プロフィール設定**: キャラ画像(アップロード or AI生成)、名前、自己紹介、**事前質問を3つまで**登録
2. **初期設定**: **最初の挨拶文(初回メッセージ)**、ユーザーへの呼び方、キャラ説明(性格・口調・専門分野)、**おすすめ回答3つまで**(=返信候補)
3. **メディア設定**: シーン画像の追加/AI生成、画像へのタイトル・シーン名付与、チャット内自動呼び出し設定
4. **キーワードブック**: トリガーワード+同義語・類義語登録 → 該当ワード出現時に画像・回答を自動表示(例:「コンサルティング」に「コンサル」「アドバイス」「指導」を紐付け)
5. **公開設定**: **公開範囲(公開/非公開)**、カテゴリー選択、ハッシュタグ登録
- テンプレート種別がデータ上存在: `talk / rolePlaying / simulation / custom / default`(HTML内`template`フィールド)+builderType(TARGET/GENRE/TYPE)
- 見た目・性格・口調・関係性・世界観をテキストで指定。運営審査あり(月1キャラ作成+審査合格が報酬条件)
- ビジュアルノベル制作ツールは別途: 背景/日付/場所、主要・サブ登場人物、ルート分岐フローチャート、好感度等ステータス変化、冒頭選択肢
- [推定] プロンプト三層構造(機能・キャラ・システム)のテンプレート化で入力を簡素化(取材記事の技術説明)

## 6. 課金構造

- 通貨: **ゴールド(G)**。前払式支払手段(資金決済法表記あり)。購入G無期限/ボーナスG1年失効
- **無料枠**: 会員登録で320G(チャット最大約100回分)、ウェルカムミッション200G、毎日ログインボーナス24G(06:00-23:59受取)、通知オン30G、バッジ獲得で最大5,000G。**サブスクは無し**(2026年時点)
- **消費**: メッセージ送信ごとにモード別G消費 — パワー2G(記事により3G)/ブースト5G/スーパー8G(期間限定7Gの割引実績)/ウルトラ8G/ハイパー24G。ほかリアルタイム画像作成、ユーザーノート拡張、応援(投げ銭)でも消費
- **価格**(記事掲載時点のWeb版パッケージ): 200G=280円 / 510G=700円 / 1,040G=1,400円 / 3,200G=4,200円 / 5,400G=7,000円 / 11,000G=14,000円。App Storeのアプリ内課金は「ゴールド 200〜10,000円」+初回購入限定パッケージ
- 決済: クレカ、コンビニ、QRコード、Apple Pay/Google Pay。WebはSBペイメントサービス経由
- **課金トリガー**: 無料Gの枯渇(高品質モードほど消費大)。[推定] 品質差分型アップセル(通常モードで試し→スーパー以上の記憶力・文章力を体験させて購入誘導)。App Storeレビューでは従量制の心理的負担への不満と月額制要望が複数
- **広告: なし**

## 7. コミュニティ/ソーシャル・クリエイター収益化

- いいね、コメント(キャラ単位)、フォロー(作成者)、応援ゴールド(投げ銭)、Discord公式コミュニティ、X等への共有
- ランキング: 本日/全体の人気キャラランキング。期間限定「キャラチャットランキング」キャンペーン(チャット数1位5万円/2位2万円/3位1万円のAmazonギフト券)
- **クリエイター報酬制度**(2025年7月実装、公式PR): ①作成ミッション達成で15,000G ②月1キャラ以上作成+審査合格で毎月2,000G ③自作キャラでのチャット1回ごとにモード別G還元(スーパー8G/ブースト5G/パワー3G) ④月間チャット数トップ10作成者に最大5万円相当。報酬受取には運営との取り決め合意が必要
- 実績: 韓国では月10〜20万円、最高120万円/月のクリエイター(取材記事)。日本でも「毎月6〜7万円稼いでいる」というYahoo!知恵袋投稿あり
- データモデル上、`isCertifiedCreator`(認定クリエイター)フラグ、キャラごとに`likeCount / chatCount / chatUserCount / commentCount / badges`を保持(HTML解析)

## 8. コンテンツポリシー(NSFW/恋愛)

- App Storeレーティング **16+**、アプリ内コントロールとして「年齢確認、性的内容・ヌードを含む」と明記 → 恋愛・センシティブ寄り表現を年齢確認付きで許容する設計
- **「安心フィルター」**: デフォルト適用。設定→アカウント設定→生年月日で18歳以上を登録するとオフにでき、「少し大人向けのセンシティブな会話」が可能になる。データ上も`isAdult / isConvertedToAdult`フラグをキャラ単位で保持
- 上限は存在: 過度な性的表現・極端な暴力/グロ・実在人物モデル・著作権侵害はBAN/キャラ強制削除対象。未成年キャラへの性的描写は2025年6月から自動フィルター作動。生成中にNG判定されると「回答が拒否されました」エラー
- 利用規約(第30条)で児童ポルノ等性犯罪該当行為、性的表現の入力等を禁止。未成年者は成人向けコンテンツ閲覧不可・法定代理人同意必須(第16条)
- [推定] 実運用は「ソフトNSFW可・ハードNSFW不可」のミドルレンジ。BL/夢女子系の「ダークロマンス」タグ等が公式ジャンルとして存在することから、恋愛・官能"寸止め"領域を主戦場にしている
