# SCR-006: ノベルリーダー(チャット本体) ★コア画面
- route: /story/[storyId] (ゲストモード: /story/guest ローカルのみ)
- auth: authenticated (ゲストモードのみ例外)
- purpose: 「文章が連続的に出てくるラノベ体験」の本体。没入最優先 [USER-REQ]

## Layout
```
┌──────────────────────┐
│ [←] 作品タイトル(小)   [⋯] │ ← ヘッダーは薄く。スクロールで自動非表示
├──────────────────────┤
│                      │
│  (縦スクロールの連続本文)    │
│  ── 導入 ──            │ ← introText(地の文、明朝・行間1.9・字間広め)
│  本文本文本文本文……        │
│  「セリフはカギ括弧で強調」    │ ← セリフ行はウェイト+主演キャラ色のアクセント
│                      │
│  ┌ わたし ┐             │ ← ユーザー発言は右寄せ・淡色背景・小さめ
│  │ 入力した文章 │          │
│  └──────┘             │
│  本文本文……(ストリーミング中は│
│  文字が流れ込み、末尾に ▌点滅) │
│                      │
│  [🔄書き直す] [↩少し戻る]   │ ← 最新AI応答の直下にだけ小さく表示
│  ┌選択肢カード┐            │ ← choicesがある時のみ
│  │ A: 手を取る │           │
│  │ B: 目を逸らす │          │
│  └──────────┘          │
├──────────────────────┤
│ ┌ 入力欄(1〜4行自動拡張) ┐   │
│ │ セリフか、*動作* を書く…│ ▶ │ ← 空欄で▶=「つづきを読む」に変化
│ └────────────────┘    │
└──────────────────────┘
```
- 下部タブバー非表示(没入モード)。ヘッダー/入力欄以外の装飾なし
- ダークテーマ対応(既定はOSに追従)

## Components
| Component | Behavior | Data |
|---|---|---|
| NovelStream | メッセージ列をノベル組版で連結表示。AI応答はSSEで文字単位に追記。自動スクロール(ユーザーが上に戻ったら追従停止+「↓最新へ」チップ) | GET /api/stories/:id / SSE |
| InputBar | テキスト入力。`*〜*`はイタリック地の文としてプレビュー。空欄時は▶が「つづきを読む」 | POST /api/stories/:id/messages |
| ChoiceCards | タップで選択テキストを即送信(selectedChoice記録)。「自分で書く」リンクで入力欄へフォーカス | 同上 |
| RerollButton | 最新AI応答を破棄して再生成(SSE)。長押しで「方向を指定して書き直す」(一言指示入力→再生成) | POST /api/stories/:id/messages/:idx/reroll |
| RewindButton | タップでメッセージ選択モード→選んだ位置まで巻き戻し(以降を論理削除)。確認ダイアログあり | POST /api/stories/:id/rewind |
| StoryMenu(⋯) | ドロワー: 記憶(summary閲覧+userNote編集)/ペルソナ変更/最初から新しいルートで読む/この作品ページへ/通報 | GET・PUT /api/stories/:id/memory ほか |
| GuestGate | ゲストモード4往復目の送信で登録壁モーダル(「続きを保存して読むには登録」)→SCR-017 | localStorage |

## States
- loading: 既存本文を即表示(キャッシュ)→ 差分fetch
- generating: ストリーミング中。入力欄はdisabled+「▌執筆中…」。**20秒無応答でタイムアウト表示+再試行ボタン**(AIF-001 fallback)
- error(生成失敗): 本文中にエラーカード「続きが書けませんでした[もう一度]」。直前のユーザー入力は入力欄に復元
- blocked(モデレーション): 「この展開は表現ガイドラインに触れるため書けませんでした。別の展開を試してください」+入力復元(AIF-007)
- empty(新規Story): introText+firstMessageを演出表示(150msディレイでフェードイン)

## Interactions
- 送信 → ユーザー発言を即時表示 → AI応答ストリーミング(AIF-001)。応答完了時に選択肢を確率的に添付(AIF-005、毎ターンではなく2〜4往復に1回 [ASSUMED: 選択肢過多は自由入力を阻害するため])
- 空欄送信 → 「つづきを読む」= AIが物語を進める(ナレーション継続)
- 書き直す → 直前AI応答を差し替え。長押し=指示付き再生成
- 少し戻る → 選択位置まで巻き戻し(論理削除)。巻き戻し後は入力欄フォーカス
- ← → SCR-007(本棚)へ。離脱時に要約メモリ更新をトリガー(AIF-003)

## AI Behaviors
- AIF-001: ノベル応答生成(ストリーミング) — 全送信で発火
- AIF-003: 要約メモリ更新 — 10往復ごと+離脱時にバックグラウンド発火
- AIF-005: 選択肢生成 — 応答生成に同梱
- AIF-007: 出力ライン制御 — 全応答に適用(安心フィルター状態とcontentLevelに応じたプロファイル)
