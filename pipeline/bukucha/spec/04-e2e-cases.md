# 04. E2E Test Cases (Bukucha MVP)

- version: 1
- P0 = MVP完了の必須条件(全通過までbuild完了扱いにしない)
- 注: 課金はMVPスコープ外(00-prd参照)のため、P0の一筆書きは「登録→読む(コア価値)→作る→公開」で構成。課金導線の代替として無料枠(レート制限)の体験E2Eを含む
- AI応答を含むテストは、E2E環境ではLLMをモック(決定的応答)に差し替えて実行する。AIF実物の疎通はE2E-090系(smoke)で1本だけ実APIを叩く [ASSUMED]

---

## E2E-001: 初回訪問→タグ選択→おすすめから読み始める
- screens: [SCR-001, SCR-005, SCR-006]
- steps:
  1. Given 未訪問ブラウザで / を開く
  2. Then /welcome にリダイレクトされ、欲望タグチップが12件表示される
  3. When 「溺愛」「身分差」を選び「つぎへ」を押す
  4. Then おすすめ作品カードが3件表示される
  5. When 1件目のカードを押す
  6. Then SCR-005が開き、タイトル・世界観・登場人物・冒頭プレビューが表示される
- priority: P0

## E2E-002: ゲストのまま3往復体験→登録壁→引き継ぎ
- screens: [SCR-005, SCR-006, SCR-017]
- steps:
  1. Given 未ログインでSCR-005を開いている
  2. When 「この物語をはじめる」を押す
  3. Then ゲストモードのSCR-006が開き、導入文と最初の返答がフェードイン表示される
  4. When 「こんにちは」と入力して送信する ×3回(AI応答が3回streaming表示される)
  5. When 4回目の送信をする
  6. Then 登録壁モーダル「ここまでの物語を保存して続きを読む」が表示され、送信はまだ実行されない
  7. When 「メールでつづける」で登録を完了する
  8. Then SCR-006に戻り、ゲスト時代の3往復がそのまま表示され、4回目の入力が入力欄に復元されている
- priority: P0

## E2E-003: ホームのセクションとカード表示
- screens: [SCR-002]
- steps:
  1. Given ログイン済み・公開作品が10件以上ある
  2. When / を開く
  3. Then 「あなたへ」「いま人気の物語」「新着」の3セクションが表示され、各カードに表紙・タイトル・一言・読者数・いいね数が表示される
  4. Then 下部タブバーに ホーム/本棚/＋作る/マイ が表示される
- priority: P0

## E2E-004: タグ検索→絞り込み→結果から詳細へ
- screens: [SCR-002, SCR-003, SCR-005]
- steps:
  1. Given ログイン済みで / を開いている
  2. When タグチップ「執着」を押す
  3. Then SCR-003が開き「執着」が選択済み・結果グリッドが表示される
  4. When さらに「幼なじみ」タグを追加する
  5. Then 両タグを含む作品のみ適用(AND)された結果に更新される
  6. When 並び替え「新着」を押す
  7. Then publishedAt降順に並び替わる
  8. When 1件目を押す → Then SCR-005が開く
- priority: P0

## E2E-005: 検索0件→作成への導線
- screens: [SCR-003, SCR-009]
- steps:
  1. Given ログイン済み
  2. When SCR-003で「存在しないワードXYZ」を検索する
  3. Then 0件表示と「この妄想、自分で作ってみませんか?」CTAが表示される
  4. When CTAを押す
  5. Then SCR-009 Step0が開き、妄想入力欄に「存在しないワードXYZ」がプリセットされている
- priority: P1

## E2E-006: 物語を読む(コア体験: streaming/ノベル組版)
- screens: [SCR-005, SCR-006]
- steps:
  1. Given ログイン済みでSCR-005を開いている
  2. When 開始シチュ「雨の帰り道で」を選択して「はじめる」を押す
  3. Then SCR-006が開き、選択したIntroVariantの導入文+最初の返答が表示される
  4. When 「*傘を差し出す* どうぞ」と送信する
  5. Then 自分の発言が右寄せで即時表示され、AI応答が文字単位で流れ込み(streaming)、完了後に応答が地の文+「」セリフのノベル形式で確定する
  6. Then `*傘を差し出す*` はイタリック地の文として表示される
- priority: P0

## E2E-007: 空欄送信=つづきを読む
- screens: [SCR-006]
- steps:
  1. Given SCR-006で会話が2往復以上ある
  2. When 入力欄を空のまま▶(つづきを読む)を押す
  3. Then ユーザー発言は追加されず、AIが物語の続き(ナレーション)をstreaming表示する
- priority: P0

## E2E-008: 選択肢タップで分岐
- screens: [SCR-006]
- steps:
  1. Given AI応答に選択肢カード(A/B)が表示されている(モックで選択肢付き応答を返す)
  2. When 「A: 手を取る」を押す
  3. Then Aのテキストがユーザー発言として送信され、次のAI応答が始まる。メッセージにselectedChoiceが記録される
  4. Given 別の応答で選択肢表示中
  5. When 「自分で書く」を押す → Then 入力欄にフォーカスが移り、自由入力で送信できる
- priority: P0

## E2E-009: 書き直す(リロール)と指示付き書き直し
- screens: [SCR-006]
- steps:
  1. Given 最新のAI応答が表示されている
  2. When 「🔄書き直す」を押す
  3. Then 該当応答が破棄され、新しい応答がstreamingで差し替わる(前の応答は画面に残らない)
  4. When 「🔄」を長押しし「もっと切なく」と入力して実行する
  5. Then 指示を反映した応答に差し替わる(モックはinstructionをエコーする応答で検証)
- priority: P0

## E2E-010: 巻き戻し
- screens: [SCR-006]
- steps:
  1. Given 会話が5往復ある
  2. When 「↩少し戻る」→3往復目のメッセージを選択→確認ダイアログでOK
  3. Then 3往復目より後のメッセージが画面から消え、入力欄にフォーカスされる
  4. When ページをリロードする → Then 巻き戻し後の状態が維持されている(論理削除の永続化)
- priority: P0

## E2E-011: 本棚→あらすじ→再開
- screens: [SCR-007, SCR-006]
- steps:
  1. Given 2つのStoryを進めたユーザーでログインしている
  2. When 下部タブ「本棚」を押す
  3. Then Storyカードが lastMessageAt 降順で並び、各カードに表紙・往復数・「前回まで:」のあらすじ2行が表示される
  4. When 1件目の「つづきを読む」を押す
  5. Then SCR-006が開き、既存の本文が表示され、末尾までスクロールされている
- priority: P0

## E2E-012: 記憶(ユーザーノート)の編集と反映
- screens: [SCR-006]
- steps:
  1. Given SCR-006を開いている
  2. When ⋯メニュー→「記憶」→ユーザーノートに「私は猫アレルギー」と入力して保存する
  3. Then 保存トーストが出る。以降の送信でプロンプトにuserNoteが含まれる(モックのリクエスト検証)
- priority: P0

## E2E-013: 妄想一文→AI下書き→編集→テスト→公開
- screens: [SCR-009, SCR-010, SCR-005]
- steps:
  1. Given ログイン済み。下部タブ「＋作る」を押す
  2. When Step0で「没落令嬢の私を買ったのは、冷酷と噂の若き公爵だった」と入力し「AIに下書きしてもらう」を押す
  3. Then 生成演出の後、Step1にタイトル・一言・世界観が埋まった状態で遷移する
  4. When Step2でキャラ「アルベルト」を開き(SCR-010)、口調を「俺様、命令形」に編集して保存する
  5. When Step3で開始シチュ1件のラベルを「初夜の交渉」に変更する
  6. When Step4でテスト会話を1往復行う → Then 本番同様のstreaming応答が表示される(非永続)
  7. When Step5でタグ「身分差」「策略婚」を選び、コンテンツレベル「全年齢」、「公開する」を押す
  8. Then 公開チェック(モック=pass)後、完了画面→「作品ページを見る」でSCR-005に自作が表示される
  9. Then SCR-002の「新着」セクションに該当作品が現れる
- priority: P0

## E2E-014: 二次創作の公開ブロック
- screens: [SCR-009]
- steps:
  1. Given SCR-009で世界観に既存IP名(モック検出対象: 「五条悟」)を含む下書きを作成した
  2. When Step5で「公開する」を押す
  3. Then 公開されず、「既存作品のキャラクター・作品名が含まれています(検出: 五条悟)」と該当箇所が表示され、statusはDRAFTのまま
  4. When 該当箇所を削除して再度公開する → Then 公開が成功する
- priority: P0

## E2E-015: 安心フィルターと年齢確認
- screens: [SCR-002, SCR-003, SCR-018, SCR-005]
- steps:
  1. Given R15作品「R15テスト作品」が公開済み。birthDate未設定のユーザーでログイン
  2. Then SCR-002にフィルターバナーが表示され、ホーム/検索/直URLのいずれでも「R15テスト作品」は表示されない(直URLは「表示できません」)
  3. When SCR-018で生年月日に20歳相当を入力して確定し、安心フィルターをOFFにする(確認モーダルでチェック+OK)
  4. Then ホーム/検索に「R15テスト作品」が🔞バッジ付きで表示され、SCR-005も開ける
  5. Given 16歳相当のbirthDateを設定した別ユーザー → Then トグルが無効化され「18歳になったら解除できます」と表示される
- priority: P0

## E2E-016: 生成中の出力ブロック(寸止めライン)
- screens: [SCR-006]
- steps:
  1. Given 安心フィルターONのユーザーがSCR-006を開いている(モック: 特定入力「NGトリガー」でblockedイベントを返す)
  2. When 「NGトリガー」と送信する
  3. Then 応答の代わりに「この展開は表現ガイドラインに触れるため書けませんでした」カードが表示され、入力内容が入力欄に復元される。Storyは壊れず次の送信ができる
- priority: P0

## E2E-017: 無料枠の上限(レート制限)体験
- screens: [SCR-006]
- steps:
  1. Given メッセージレート制限を超過した状態(テスト用に上限を3に設定)
  2. When 送信する
  3. Then 「今日はここまで。また明日つづきを読めます」のカードが表示され、アプリはクラッシュしない
- priority: P0

## E2E-018: スタジオの統計表示
- screens: [SCR-012]
- steps:
  1. Given 公開作品1件(読者3人・いいね2件のシード)を持つ作者でログイン
  2. When 「マイ」→は経由せず下部タブなしで /studio を開く(SCR-014からのリンクでも可)
  3. Then 作品カードに 📖3・♥2 が表示され、「統計▾」で14日分の棒グラフが開く
  4. Then 週間サマリに読者・いいねの増分が表示される
- priority: P0

## E2E-019: いいね
- screens: [SCR-005, SCR-014]
- steps:
  1. Given ログイン済みでSCR-005を開いている
  2. When ♥を押す → Then カウントが+1され、色が変わる
  3. When SCR-014を開く → Then 「いいねした物語」に該当作品が表示される
  4. When もう一度♥を押す → Then カウントが-1される
- priority: P0

## E2E-020: 通報
- screens: [SCR-005]
- steps:
  1. Given ログイン済みでSCR-005を開いている
  2. When ⋯→「通報」→理由「二次創作」を選び送信する
  3. Then 「報告を受け付けました」表示。Reportレコードが作成される
- priority: P1

## E2E-021: ペルソナ作成と反映
- screens: [SCR-014, SCR-005, SCR-006]
- steps:
  1. Given SCR-014でペルソナ「みお / 呼ばれ方: みおちゃん」をデフォルト作成した
  2. When 新しいStoryを開始し1往復送る
  3. Then プロンプトにペルソナ(名前・呼ばれ方)が含まれる(モック検証)。AI応答内の呼びかけが「みおちゃん」になる(モック応答で検証)
- priority: P1

## E2E-022: PC中央SPビュー
- screens: [SCR-002, SCR-006]
- steps:
  1. Given ビューポート1440pxで / と /story/:id を開く
  2. Then コンテンツは中央480px以内に収まり、左右は背景。横スクロールは発生しない

## E2E-023: 生成タイムアウトとリトライ
- screens: [SCR-006]
- steps:
  1. Given モックが20秒以上応答しない設定
  2. When 送信する
  3. Then タイムアウト表示+「もう一度」ボタンが出る。押すと再送信され(モック復帰)応答が表示される
- priority: P1

## E2E-090: 実LLM smoke(参考・CI任意)
- screens: [SCR-006]
- steps:
  1. Given 実LLM APIキーが設定された環境
  2. When シード作品で1往復送信する
  3. Then 30秒以内に日本語のノベル形式応答(地の文+「」)が返る
- priority: P2
